# 教程页内嵌字体的许可证

`docs/tutorial-zh.html` 是个单文件网页，为了不依赖任何外部 CDN，
它把用到的字体做了**子集化**并以 data URI 内嵌。用到的两套：

| 字体 | 用途 | 许可证 | 原文 |
|---|---|---|---|
| Noto Sans CJK SC | 正文和标题（子集 573 字形） | SIL Open Font License 1.1 | `NotoSansCJK-copyright.txt` |
| DejaVu Sans Mono | 代码块（子集 136 字形） | Bitstream Vera Fonts License | `DejaVu-copyright.txt` |

两者都允许嵌入文档、允许再分发子集，条件是随附许可证原文 —— 就是本目录这两个文件。

页面里其它素材（RetroArch 界面截图）来自实际运行的 RetroArch，仅作问题说明用。
